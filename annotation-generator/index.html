How this works

Quick start

  1. Load a record. Type the last 5 digits of the UPC and press Load. It finds the latest current revision.
  2. Pick your options. Turn the finish chip, window chip and unused swatches on or off.
  3. Check the values. Everything pulled from Quickbase can be edited before you download. Click anything on the preview to jump to its field.
  4. Check the colors. Each cylinder has a box per chip. The little square beside it shows the color it resolved to.
  5. Download the JSX. In Illustrator choose File → Scripts → Other Script… and pick the file. It draws all three layouts and asks where to save the .ai.

What's new

  • Dieline record ID now comes from the family's current spec page ("Record ID#").
  • Initials after the date (01-01-2026_QM) come from your Quickbase login and can be edited.
  • Chips stack in one column: Soft Touch, Special Dieline, Window. Each can be switched on or off (Special Dieline is always on).
  • MATTE chips are left with no fill and no spot swatch.
  • C, M, Y, K, W show as CYAN, MAGENTA, YELLOW, BLACK, WHITE, and print as 100% of one plate.
  • Pantones show as "P 185 C" and still convert to the right swatch.
  • Color names are centered under the chip, wrap to two lines and shrink only if needed.
  • Labels and values sit one space apart; text and borders are 100% K black.
  • Fonts: Demo Grotesk Bold for labels, headings and color names; Book for everything else.
  • The preview matches Illustrator: it's drawn from the same coordinates as the JSX and uses the fonts installed on this computer, the same way Illustrator does.
  • Color names are uppercase in the preview and the output, however they're typed.
  • The date is today's date when you load a record (you can still change it).
  • Copy from Back / Bottom: a button on the Side colors copies every Back / Bottom color across.

Questions

Why is the Dieline record ID blank?

The artwork's family has no spec linked in Quickbase, or it couldn't be read. Type the ID from the family spec page into the field. The status message under Load says which.

Which spec does the Dieline record ID use?

The family's current spec revision (the same one the family page calls current). If a newer revision is made later, annotations generated after that show the new ID.

Where do the initials after the date come from?

The first two letters of the signed-in person's email, uppercased (maintainer@… → QM). Change them in the Initials field, or clear it to leave the date on its own.

How should I type color names?

Process: C, M, Y, K, W or CYAN, MAGENTA, YELLOW, BLACK, WHITE. Pantone: P185C, P 185 C, PMS 185 or PANTONE 185 C (add U for uncoated). Spot black: SPOT K. Anything else is printed as typed.

Why is my MATTE chip empty?

On purpose: any name containing MATTE leaves the chip with no fill and adds no spot swatch.

Why didn't my custom ink get a spot swatch?

Only Pantone colors and SPOT K get named spot swatches. A custom name (for example TOUCH OF GOLD) is printed under a white chip; add its swatch in Illustrator by hand.

Why is a color name smaller than the others?

Names start at full size and shrink only as much as needed to fit two lines under the chip (never below 6 pt), so nothing overflows.

How do I hide chips that aren't used?

Tick "Hide unused color swatches". Chips with no color name are left out of every layout.

How do I change or remove the Soft Touch chip?

Untick "Finish chip" to remove it, or change its text in the Finish chip field (for example GLOSS). It appears on all three layouts.

How do I add a window chip?

Tick "Window chip". A light blue WINDOW chip is added under Special Dieline.

Why is the preview in Arial?

The preview uses the fonts installed on this computer, exactly like Illustrator will. If Demo Grotesk Bold or Book isn't installed here, that part shows (and prints) in Arial. The Fonts list says which are installed and has the downloads.

How do I copy the Back / Bottom colors to Side?

Click Copy from Back / Bottom next to the Side heading in Cylinder colors. It replaces all ten Side colors; you can edit them afterwards.

Why does Illustrator say Arial was used?

Demo Grotesk isn't installed on that computer. Download the fonts from the Fonts list, install them, restart Illustrator and run the JSX again.

Why are some characters in Arial?

The Demo Grotesk files we have are trial versions that only contain letters, numbers, spaces and periods. Other characters (: # & / - and so on) are set in Arial so nothing is missing. The licensed family would remove the fill-ins.

Can I click the preview?

Yes. Anything with a dashed outline on hover jumps to its field. The logo, address, Print Method and Special Dieline aren't editable, so they don't respond. Drag to move around; use the mouse wheel or − / + to zoom, and Fit to reset.

What does "Show tags" do?

It labels each item with the name it gets in Illustrator (for example V1.BRAND_NAME), so you can find it in the Layers panel.

I changed something after downloading. Now what?

Download the JSX again. Each download contains the values on screen at that moment.

Nothing loads when I press Load.

Open this page from Quickbase while signed in, and enter exactly 5 digits. If no current revision matches, the latest revision is used; if none match at all, the message says so.

The layout looks cramped.

Use the Layout button to switch between automatic, stacked and side-by-side views. Dark mode is next to it.
