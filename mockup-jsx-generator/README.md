# Mockup Jsx Generator

Generates an Illustrator script that draws a mockup dieline from a request's dimensions.

Open `index.html` in a browser. It runs on a built-in mock of the Quickbase API, so no account or server is needed. Changes last until you reload. Try mockup `1501`, then Submit Mockup to download a script. The script comes from a simplified stand-in template.

All companies, products, people and records here are fictional.
